fazer o fork e clonar LOCALMENTE - não pode estar na nuvem!!! - deste projeto conforme video do onboarding:
    - https://www.youtube.com/watch?v=1nfb6sLzVPs&list=PL8YYHe7VHQ9BJHMSm4SHIJWy3GxEj_nVc&index=6

 conferir que tem node instalado na última versão LTS - se tiver a normal, e for maior que a LTS funciona também

abrir cmd e rodar no usuario
    - npm i -g pnpm
    - exemplo: C:\Users\pigab>npm i -g pnpm

abrir o projeto no VS Code, dentro de "mentores-frontend":
    - criar um arquivo novo e nomear ".env"
    - colar os seguintes parâmetros e salvar:
        NEXT_PUBLIC_API_URL=https://p01--mentores-backend-api-dev--bj8pjy8s82zl.code.run
CALENDLY_CLIENT_ID=N24tR3RHkxh41T1wX2Gxm0cK7BdyIWicqVuLGDLrVSo
CALENDLY_REDIRECT_URI=https://p01--mentores-backend-api-dev--bj8pjy8s82zl.code.run/calendly/callback


abrir o terminal dentro do VS Code, no projeto e rodar o comando:
    - pnpm i

depois, rodar um e depois o outro:
    - pnpm build
    - pnpm start

vai sser disponibilizada uma URL localhost, abrir no browser e usar seu usuário e senha cadastrados pra testar, caso não tenha usuário, criar.
